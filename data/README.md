# Data

`raw/online_retail.zip` contains `data.csv`, the **UCI Online Retail** dataset
(Chen, 2015, https://doi.org/10.24432/C5BW33, CC BY 4.0): 541,909 invoice lines
from a UK-based online gift wholesaler, 2010-12-01 to 2011-12-09.

| column | meaning |
|---|---|
| InvoiceNo | 6-digit invoice id; a leading `C` marks a cancellation / return |
| StockCode | product code; non-merchandise codes (POST, DOT, M, D, AMAZONFEE, …) are excluded in cleaning |
| Description | product name |
| Quantity | units per line (negative on returns) |
| InvoiceDate | `M/D/YYYY H:MM` |
| UnitPrice | GBP per unit |
| CustomerID | 5-digit customer id; missing for ~25% of lines (guest checkout) |
| Country | customer country |

The loader reads the zip directly (`pandas.read_csv` handles single-file zips), so nothing needs unzipping.

`processed/` is regenerated by `python -m rfm.pipeline`. It is committed so the
dashboard works straight after cloning.
